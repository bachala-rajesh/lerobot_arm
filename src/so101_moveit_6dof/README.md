# so101_moveit_6dof

MoveIt2 configuration package for the SO-101 arm — **6DOF variant**.

Generated by MoveIt Setup Assistant, then customized for this project.

---

## Config files

| File | Purpose |
|------|---------|
| `so101_arm.srdf` | Planning groups, end-effectors, named positions |
| `so101_arm.urdf.xacro` | URDF entry point (wraps `so101_description`) with `dof:=6` |
| `kinematics.yaml` | IK solver config (KDL) |
| `joint_limits.yaml` | Per-joint velocity and acceleration limits |
| `moveit_controllers.yaml` | Maps MoveIt planning groups to ros2_control controllers |
| `initial_positions.yaml` | Home position for simulation |
| `pilz_cartesian_limits.yaml` | Cartesian speed limits for Pilz planner |
| `sensors_3d.yaml` | 3D sensor (OAK-D) config for collision avoidance |

---

## Launch files

| File | Purpose |
|------|---------|
| `move_group.launch.py` | Start MoveIt move_group node |
| `moveit_rviz.launch.py` | Start RViz with MoveIt plugin |
| `rsp.launch.py` | Robot state publisher only |
| `spawn_controllers.launch.py` | Spawn ros2_control controllers |
| `static_virtual_joint_tfs.launch.py` | Publish static TF for virtual joints |
| `warehouse_db.launch.py` | Start MongoDB warehouse for motion plan storage |
| `demo.launch.py` | Full demo: move_group + RViz (standalone, no real robot) |
| `setup_assistant.launch.py` | Re-open MoveIt Setup Assistant to edit this config |

These are not called directly in normal use — `so101_bringup/launch/moveit_server_sim_6dof.launch.py` wraps them.
